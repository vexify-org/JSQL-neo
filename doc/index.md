## ⚡ 核心特性速览

| 特性 | 说明 |
|---|---|
| 多协议 | MySQL / PostgreSQL / MongoDB / Redis 一端口同时服务 |
| 零依赖 | 数据库核心零运行时依赖 |
| 三引擎 | Native (N-API) / WASM / Pure JS |
| 存储模式 | 内存模式 / 混合模式 / 磁盘模式 |
| 内置 UI | 零依赖 Web 管理界面 + HTTP API |
| TUI | 交互式终端，Tab 补全、CJK 对齐 |
